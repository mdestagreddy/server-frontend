# Portfolio Frontend

ReactJS + Vite frontend for portfolio website.

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Copy `.env.example` to `.env` and configure API URL.

3. Start development server:
   ```
   npm run dev
   ```

4. Build for production:
   ```
   npm run build
   ```

## Deployment

Build the project and serve the `dist` folder with Nginx or any static file server.
